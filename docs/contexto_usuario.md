Objetivo

Padronizar o design de todas as páginas sem alterar suas estruturas ou funcionalidades.

Regras

Mantenha a mesma identidade visual em todo o site.
Preserve a responsividade para desktop, tablet e mobile.
Reutilize classes e estilos sempre que possível, evitando CSS duplicado.
Mantenha a estrutura específica de cada página.
Mantenha todo o conteúdo e componentes existentes.

Não altere links, formulários, eventos, IDs ou classes utilizadas pelo sistema sem necessidade.

index.html
index.css
Todas as outras páginas HTML
